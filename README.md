# FML Quartett

Quartett-Karten der eigenen RC-Modelle als Web-App (iPhone: Safari → Teilen → Zum Home-Bildschirm).

Dieses Repo enthält nur den App-Code. Die Modelldaten liegen in einem privaten Repo und werden
mit einem persönlichen, nur lesenden GitHub-Token geladen, der ausschließlich auf dem Gerät gespeichert wird.
