Einrichten

Die Modelldaten liegen in deinem privaten Repo. Die App braucht einmalig einen GitHub-Token mit Lesezugriff. Er wird nur auf diesem Gerät gespeichert.

  1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token
  2. Repository access: Only select repositories → FML-Github
  3. Permissions: Contents → Read-only
